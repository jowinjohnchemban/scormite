# AGENTS.md

Everything about this project — what it is, its rules, conventions,
architecture, and workflow — is documented in [`docs/`](docs/README.md),
for people and agents alike. Read before changing anything:

1. [`docs/README.md`](docs/README.md) — the documentation index
2. [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) — rules, conventions, definition of done
3. [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) and [`docs/ROADMAP.md`](docs/ROADMAP.md)

Agent-only working notes (progress logs, research scratch) go in
`.agent-docs/`, which is git-ignored. Shared knowledge always goes in `docs/`.
